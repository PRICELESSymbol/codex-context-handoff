# Codex Context Handoff

面向 Windows Codex 桌面端的实验性对话交接工具。窗口占用达到 60% 时，通过生命周期钩子提示源对话保存交接记录，在同一项目中创建新对话继续任务。

**当前状态为实验版。阈值逻辑和同项目创建对话分别经过验证；已信任钩子触发到新对话自动接手的完整流程尚未验收。** 交接依赖模型执行指令及桌面工具可用性。本项目没有使用 OpenAI 官方商标资产，也不是官方插件。

## 功能

- 按最近一次请求的 token 用量与窗口容量计算占用率。
- 本地项目对话默认启用，普通聊天手动启用。
- 项目交接以根目录的 handoff.md 为入口，独立保存每个源对话的交接记录。
- 指示源对话核对项目 ID，再在同一项目创建接手对话。
- Tkinter 面板显示最近 100 个本地对话，可分别开启或关闭。
- 对已启用的会话，在自动压缩前请求暂停，保留原记录。

## 环境要求

- Windows，Python 3.10 或更新版本，包含标准库 tkinter。
- 已安装并登录 Codex 桌面端。
- 桌面端支持 PostToolUse、UserPromptSubmit、Stop、PreCompact 四类钩子。
- 源对话具有 list_projects、list_threads、create_thread 桌面工具。
- 默认读取用户目录下的 .codex，也支持 CODEX_HOME。

本机兼容性检查基于桌面配套 codex-cli 0.167.0-alpha.3.2。工具读取 state_5.sqlite、.codex-global-state.json 和会话日志中的内部字段；Codex 更新后可能需要适配。云端、远程主机和子代理不在已验证范围内。

## 安装

将仓库克隆到准备长期保留的位置，在该目录执行：

~~~powershell
python -X utf8 manager.py install
~~~

安装程序合并用户 .codex/hooks.json，写入前备份已有文件。四个钩子的命令指向当前 Python 解释器和本仓库 manager.py 的绝对路径。移动仓库或解释器后，应先在 /hooks 禁用旧条目，再从新位置安装。

使用与桌面端配套版本一致的 Codex CLI，输入 /hooks，检查并信任本工具的四个条目。PATH 中的 codex 可能是另一版本。若桌面支持钩子管理，也可以在那里完成审核。等待正在执行的任务结束，再重新打开桌面端加载新配置。

在已有安装的电脑上，请选择一个保留位置，避免重复注册两份不同路径的工具。

## 使用

~~~powershell
python -X utf8 manager.py panel
~~~

选择对话后可开启或关闭自动交接，点击刷新更新占用率。面板关闭后，Codex 仍可调用已信任的钩子。工具不会自行唤醒没有新事件的闲置对话。

项目交接指令要求源对话依次执行：

1. 保存完整交接到 .handoffs/<源对话ID>/<唯一交接批次>/handoff.md。
2. 备份并更新项目根目录 handoff.md，保留其他任务条目。
3. 回读确认保存成功，在相同项目 ID 下创建新对话。
4. 首条消息提供项目入口、本次交接文件的绝对路径和源对话 ID。
5. 新对话读取记录，核实现场，继续未完成工作。

交接内容包括目标、最新要求、授权范围、文件位置、Git 状态、验证证据、仍在运行的进程和下一步。任务已完成或正在等待用户时，指令允许正常结束或等待。

## 运行边界

检查发生在提交消息、工具调用结束和本轮结束时。占用率可能从低于 60% 直接跳到更高值。模型仍需消耗上下文生成交接摘要。

若自动压缩先发生，PreCompact 会请求在压缩前暂停。这个兜底路径会中止当前工作，可能需要人工继续。钩子未信任、接口变更或读取失败时，不能保证阻止压缩。

项目归属核对、文件备份、创建去重、同项目创建和接手确认通过模型指令实现，没有跨会话事务锁或确定性的交接状态机。多个源对话同时更新根目录 handoff.md 仍可能发生覆盖；独立记录和首条消息中的路径用于保留各自上下文。当前版本不能保证任意长任务全程无人干预。

对于活动 Goal，源对话还需正确结束或处理原目标，避免旧会话继续自动执行。

## 数据与停用

- 只读访问 Codex 的会话数据库、项目元数据与日志。
- 本工具的开关及事件去重记录写入 .codex/context-handoff/control.sqlite。
- 安装会修改 .codex/hooks.json，并保留备份。
- 交接文件由源对话按指令写入项目目录。
- 无独立网络上传功能。模型执行交接仍使用现有 Codex 服务及正常额度。
- 在 /hooks 中禁用四个本工具条目即可停止自动交接。
- 不要向仓库提交实际会话日志、交接文件、身份凭据或用户数据库。

## 测试

~~~powershell
python -B -X utf8 tests/test_manager.py
~~~

测试使用系统临时目录中的合成数据，覆盖阈值边界、累计用量排除、项目默认规则、普通聊天开关、事件去重、压缩拦截、压缩后的旧用量失效、交接指令顺序、重复安装。测试临时文件保留供排错。

GitHub Actions 在 Windows 和 Python 3.12 下执行相同检查。CI 不访问真实 Codex 登录态，因此不能证明桌面端到端交接成功。

## 开发

运行时仅依赖 Python 标准库。核心代码在 manager.py，回归脚本在 tests/test_manager.py。提交修改前运行测试，说明使用的桌面端版本及验证范围。报告问题时请移除真实任务内容、路径中的个人信息和凭据。

发布版本 v0.1.0，为实验性源码版本。目前未声明开源许可证。
